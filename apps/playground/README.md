# Playground

## Purpose

Provides a lightweight place to experiment with shared platform patterns before promotion into packages.

## What Belongs Here

- Internal experiments.
- Prototype compositions.
- Temporary examples for review.

## What Does Not Belong Here

- Production client code.
- Business rules intended for a specific client.
- Stable package APIs.

## Allowed Dependencies

- Shared platform packages.
- Lightweight development dependencies when the app is implemented.

## Examples of Future Exports

- Prototype shell scenarios.
- Experimental grid examples.
- Pattern comparison pages.
