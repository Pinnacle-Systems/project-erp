# @erp-ui-platform/mobile-patterns

## Purpose

Defines mobile interaction grammar for focused companion workflows.

## What Belongs Here

- Mobile task flows, bottom sheets, drill-down flows, capture patterns, mobile approval responses, and task summaries.

## What Does Not Belong Here

- Desktop dense workspaces.
- Full desktop transaction completion flows.
- Client-specific scanner rules.
- Mobile-only business rules.

## Allowed Dependencies

- `@erp-ui-platform/layout-shells`
- `@erp-ui-platform/app-components`
- `@erp-ui-platform/primitives`
- `@erp-ui-platform/tokens`
- `@erp-ui-platform/capability-contracts`
- `@erp-ui-platform/validation-ui`
- `@erp-ui-platform/workflow-actions`
- `@erp-ui-platform/approval-ui`
- `@erp-ui-platform/document-ui`
