# @erp-ui-platform/editable-grid

## Purpose

Provides reusable editable grid behavior for ERP data entry and review.

## What Belongs Here

- Keyboard navigation, cell focus, row selection, inline validation display, column sizing, and row operation UI behavior.

## What Does Not Belong Here

- Pricing calculations.
- Tax calculations.
- Inventory rules.
- Client-specific columns.
- Client-specific lookup providers.

## Allowed Dependencies

- `@erp-ui-platform/app-components`
- `@erp-ui-platform/primitives`
- `@erp-ui-platform/tokens`
- `@erp-ui-platform/capability-contracts`
- `@erp-ui-platform/validation-ui`
