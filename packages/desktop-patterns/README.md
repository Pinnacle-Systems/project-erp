# @erp-ui-platform/desktop-patterns

## Purpose

Defines desktop interaction grammar for dense ERP workspaces.

## What Belongs Here

- Dense workspace layouts, split panes, keyboard-first workflows, desktop review surfaces, and desktop action placement.

## What Does Not Belong Here

- Mobile task flows.
- Client-specific modules.
- Posting rules.
- Pricing or approval hierarchy logic.

## Allowed Dependencies

- `@erp-ui-platform/layout-shells`
- `@erp-ui-platform/app-components`
- `@erp-ui-platform/primitives`
- `@erp-ui-platform/tokens`
- `@erp-ui-platform/capability-contracts`
- `@erp-ui-platform/validation-ui`
- `@erp-ui-platform/workflow-actions`
