# Storybook

## Purpose

Documents shared platform packages, approved component usage, and interaction behavior.

## What Belongs Here

- Stories for tokens, primitives, app components, ERP patterns, shell patterns, and states.
- Mock data for platform examples.

## What Does Not Belong Here

- Client-specific business rules.
- Real client data.
- Client app implementation code.

## Allowed Dependencies

- Shared platform packages.
- Storybook dependencies when the app is implemented.

## Examples of Future Exports

- Storybook configuration.
- Platform component stories.
- Visual review scenarios.
